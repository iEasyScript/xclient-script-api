Transition

public final class Transition<S extends Enum<S>>

One edge of a StateMachineScript: when the machine is in from and condition holds, it moves to to.

Built fluently: 


Transition.from(State.BANKING)
    .when(Inventory::isEmpty, "inventory empty")
    .because("done banking")
    .goTo(State.WALKING)
