StateMachineScript

public abstract class StateMachineScript<S extends Enum<S>> extends Script

A Script organised as an enum of states and a list of Transitions.

The subclass schedules its own loop and calls step on each pass. A step runs the Script guard, fires the first transition out of the current state whose condition holds, publishes a StateSnapshot, and then runs onState for the (possibly new) state. Running machines are listed in getRegistry by simple class name so debugging tools can show their snapshots.

Everything except getSnapshot and getRegistry is meant to be used from the script's own thread.
