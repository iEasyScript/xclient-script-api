BreakHandlerScript

public class BreakHandlerScript extends Script

Version 1 break handler: a once-a-second state machine that pauses every script, optionally logs out, waits out the break, logs back in and resumes.

Each state has a handler that does its work and answers the state to move to next, or null to stay. All moves then go through enter, which owns the bookkeeping that comes with a state change.

Threading: the loop runs only on this script's own scheduler thread, never the client thread. It hops to the client thread in exactly two places (the ban-screen read and the pre-break world read), and both hops only read state. Window-title writes are always posted to the Swing thread. The public static accessors are plain volatile or atomic reads and are safe from any thread.
