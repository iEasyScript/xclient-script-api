Preconditions

public final class Preconditions

Ready-made Preconditions built only on the existing bot utilities and caches. Each check is evaluated when the guarded step runs, on the script thread; the utilities underneath do their own client-thread hops. Nothing here clicks or changes game state, with one inherited exception: isOpen enters the bank PIN if the PIN screen is up, as it does everywhere else it is called.
