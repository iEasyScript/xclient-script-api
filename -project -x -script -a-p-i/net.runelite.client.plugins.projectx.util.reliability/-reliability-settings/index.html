ReliabilitySettings

public final class ReliabilitySettings

The player's "Script reliability" settings, as one immutable snapshot.

The values come from ProjectXConfig; ProjectXPlugin publishes a new snapshot through update whenever one of them changes, so a running script picks the change up on its next step without restarting. Every value is clamped to its range when read, so a hand-edited or out-of-date profile can never make a script retry 900 times or stop after zero failures.
