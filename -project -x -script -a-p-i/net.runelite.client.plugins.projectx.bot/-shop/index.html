Shop

public class Shop

Opening shops, buying from them, checking their stock and closing them.

Stock is never read from the interface: shopItems is replaced by the plugin whenever a shop container changes, and every stock query reads that list. The list is not cleared when a shop closes, so it shows the last shop seen until the next update.
