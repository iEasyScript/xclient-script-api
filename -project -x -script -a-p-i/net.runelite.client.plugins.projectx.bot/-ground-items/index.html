GroundItems

public class GroundItems

Items lying on the ground: finding them, clicking them and looting them.

Two sources are used. The looting helpers read RuneLite's ground-items table (getGroundItems, filled while the Ground Items plugin runs); the scene readers (getAll...) read tiles on the client thread. Every click goes through the tile-item cache and click, so true from a click means it was dispatched, not that the item reached the inventory.

Looting pauses every other script while it runs (see runWhilePaused).
