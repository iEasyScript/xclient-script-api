Prayers

public enum Prayers

Prayers: turn them on and off, check points, quick prayers, flicking. 


Prayers.toggle(Prayers.PROTECT_MELEE, true);
if (Prayers.isPrayerActive(Prayers.PIETY)) { ... }
Content copied to clipboard

Each constant is a prayer (Prayers.PIETY); the static methods act on them. Named Prayers so it does not clash with RuneLite's net.runelite.api.Prayer.
