Item

public class Item

A snapshot of one item stack: id, quantity, slot and facts taken from its definition.

getId, getQuantity and getSlot are plain field reads. The definition-backed getters load the definition on first use when the item was built without one; each failed load costs one client-thread round trip, so compare items by id where you can.
