NpcStats

public final class NpcStats

Combat and slayer facts for one NPC id, as read from /npc/monsters_complete.json by NpcData.

Immutable. Getters, the all-values constructor (in field order) and the fluent Builder are generated by Lombok from the field list below, so the field order is part of the public constructor and must not change. Equality is identity on purpose.
