SceneObject

public class SceneObject implements TileObject, IEntity

A scene object (game object, wall, decoration or ground object) as scripts see it, with click to send one of its menu options through the facade.

Most TileObject members forward directly to the game's object. The name and definition are read on the client thread, and so is the local player's world view in isReachable.
