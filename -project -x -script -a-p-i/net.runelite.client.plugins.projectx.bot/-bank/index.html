Bank

public class Bank

The bank: opening and closing it, the bank PIN, reading what is in it, and moving items in and out.

Lookups read a mirror of the bank container. The mirror is fed by live bank container events and, at start-up, by a snapshot saved per RuneScape profile, so scripts can plan with the last known bank contents before the bank has been opened this session. Actions wait for a live event where it matters; see getBankLiveEpoch.

Name lookups take a minimum quantity: asking for 20 of an item by name when its only stack holds 15 finds nothing. Id lookups resolve saved ids that drifted (noted/unnoted links, renamed variants) through the item definition.

Thread rules: waits are no-ops on the client thread (they return false at once), so actions that wait for a result return false there. Widget and definition reads hop to the client thread.
