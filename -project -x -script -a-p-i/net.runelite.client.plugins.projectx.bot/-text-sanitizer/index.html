TextSanitizer

public class TextSanitizer

Strips colour tags and markup from game text. RuneLite/Jagex text cleanup helpers. Scope: removes RuneLite-style markup tags (e.g. <col=...>) and decodes the small set of entities/escapes we actively see in chat/widget strings. Not a general-purpose HTML sanitizer.
