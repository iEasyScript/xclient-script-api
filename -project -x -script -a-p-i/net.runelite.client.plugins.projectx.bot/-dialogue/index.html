Dialogue

public class Dialogue

Chat dialogues: continue prompts, option menus, message boxes and the make-X ("combination") menu.

Options are chosen with key presses, never with the mouse: an option's own key binding when it has one, otherwise its on-screen number. Waits are meant for script threads and return false at once on the client thread.
