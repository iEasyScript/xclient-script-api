Slayer

public class Slayer

The current Slayer task: its name and kill count, the monsters and where to find them, the weakness item and protective gear it needs, walking to a master, and the item teleports a route to the task depends on.

Varps come from the cached player state and game database reads hop to the client thread, so everything here may be called from a script thread.
