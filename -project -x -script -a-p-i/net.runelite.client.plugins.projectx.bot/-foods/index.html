Foods

public enum Foods

Foods a script can eat. Each row reads: display name, item id, hitpoints healed, and, for fast (combo) foods only, an eating delay of 1. Rows without a delay use the standard delay of 3.

The constant names are stored in saved script settings, and callers that match foods by name walk values in order and take the first hit (so "Potato" is tried before "Baked Potato"). Neither the names nor the order may change.
