Tiles

public abstract class Tiles implements Tile

Scene-grid helpers: walkability, reachability, local routes and the shared dangerous-tile tracker.

Every client read goes through one helper: inline when already on the client thread, otherwise through ClientThread.invoke(Supplier), which waits up to 10 s and throws on timeout. With no client at all, each member returns its documented fallback.

The scene grid is 104 x 104; a scene position is in bounds when both coordinates are in 0..103.
