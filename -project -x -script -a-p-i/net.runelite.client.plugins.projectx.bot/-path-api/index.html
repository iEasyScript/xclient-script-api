PathApi

public class PathApi

What scripts and the walker may see and change of the route planner's shared state.

The route planner keeps its state in static fields of ShortestPathPlugin. This class is the one sanctioned door to it: each call reads or writes that state at the moment it is made and hands back the planner's own live objects, with the same threading rules and exceptions as the planner. Nothing is remembered here between calls.

Members are grouped by what a caller is doing: following the current search, tuning the planner, managing the walking session, drawing the destination on the world map, and inspecting the transport graph.
