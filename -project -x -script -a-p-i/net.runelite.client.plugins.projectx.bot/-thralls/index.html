Thralls

public enum Thralls implements Spell

Arceuus thralls. Represents the different types of thralls that can be summoned using the Arceuus spellbook.

Each thrall has a corresponding spell and type (Magic, Ranged, or Melee). Thralls vary in strength from Lesser to Superior to Greater.
