Combat

public class Combat

Combat helpers: the special attack orb, combat state, attack range, attack style, autocast and auto retaliate.

Every member is static. Game state that needs the client thread is read through ClientThread.runOnClientThreadOptional; option varps come from the player state cache. Waits use Global and so give up at once when called on the client thread.
