NpcQuery

public final class NpcQuery extends AbstractEntityQueryable<NpcQuery, Npc> implements IEntityQueryable<NpcQuery, Npc>

A search over the NPCs in the scene. Start one with query, add filters, then finish with a terminal such as nearest(), nearestReachable(), first() or list(): 


Npc match = Npcs.query().nameEquals("Cow").nearestReachable();
if (match != null) {
    match.interact("Attack");
}

Filters: nameEquals, withName, withNames, withNameContains, withId, withIds, within, where, fromWorldView. Name filters read each entity's name on the client thread, so a name search off the client thread is cheaper with the *OnClientThread() terminals (nearestOnClientThread(), firstOnClientThread(), toListOnClientThread()).
