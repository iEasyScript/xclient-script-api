Equipment

public class Equipment

What the player is wearing, and the worn-item actions (remove, teleports and other item ops).

The worn items are cached as one immutable list in ascending slot order. The plugin replaces it on the client thread whenever the worn container changes, so any thread may read it. Every search below walks that list, so "first" always means the lowest slot.

Each search comes in seven shapes (no filter, predicate, slots, ids, names with an exact flag, one name with an exact flag, and names matched partially) for three answers: a stream (all), the first hit (get) and a yes/no (isWearing).

Actions report true once the menu entry was dispatched; they do not wait for the game to react.
