Project X Script API/net.runelite.client.plugins.projectx.bot

Package-level declarations

The action API. Each helper is a class of static methods (Inventory.isFull(), Bank.depositAll()); searches go through query() on Objects, Npcs, GroundItems and Players, and return SceneObject, Npc, FloorItem and PlayerModel.
