Npcs

public class Npcs

NPC helpers: finding NPCs in the scene and sending them menu actions.

New code should use query or stream: they cover every world view and read the per-tick NPC cache. The getNpc/getNpcs family is the older scanner. It looks at the top-level world view only, hands out LegacyNpc wrappers and orders them nearest first.

Name filters come in two modes. Exact compares ignoring case. Partial lower-cases both the NPC name and the search text and looks for the text inside the name. The single-name finders (getNpc, getNpcs, attack and friends) are partial; query is exact.

Threading: every game read happens on the client thread. Actions (interact, attack, pickpocket, hoverOverActor, the walking helpers) block while they work and belong on script threads.
