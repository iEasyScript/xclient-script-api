NpcData

public class NpcData

NPC facts shipped with the client: combat stats, attack styles and spawn locations, read from the JSON files under /npc/.

Nothing is loaded until loadJson runs; before that the lookups answer "not found". Loading parses a few megabytes, so call it from a script thread. Apart from getClosestLocation, which runs the walker's path search, nothing here touches the game client.
