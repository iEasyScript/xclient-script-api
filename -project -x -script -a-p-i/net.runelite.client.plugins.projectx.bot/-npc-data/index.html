NpcData

public class NpcData

NPC data loaded from the wiki dumps: stats, attack styles, locations. Named NpcData so it does not clash with RuneLite's NpcManager. This class is responsible for managing NPCs in the game. It provides utility methods for loading NPC data from JSON files and retrieving NPC stats.
