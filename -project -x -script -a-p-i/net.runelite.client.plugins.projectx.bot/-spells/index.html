Spells

public enum Spells implements Spell

Non-combat spells of all four spellbooks, plus the standard book's curses and binds.

Each constant carries its spellbook and its rune cost per cast; name and level come from the matching MagicAction. Lookups by partial name walk values in order and take the first hit, so the declaration order is significant and must be kept.
