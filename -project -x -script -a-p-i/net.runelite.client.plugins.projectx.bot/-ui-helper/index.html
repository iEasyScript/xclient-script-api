UiHelper

public class UiHelper

Where scripted clicks land: clickboxes, click points, keeping clicks off the fixed interface panels, plus a few text and version helpers.

The "fallback rectangle" (getDefaultRectangle) stands for "no real clickbox" and is recognised by isFallbackRectangle.
