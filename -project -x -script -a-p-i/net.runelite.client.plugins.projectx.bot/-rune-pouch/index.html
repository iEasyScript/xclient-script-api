RunePouch

public class RunePouch

The rune pouch: what it holds (kept in step with the game's varbits), and loading it at a bank, either from a saved loadout or by withdrawing each rune.

onVarbitChanged and onWidgetLoaded are fed by the plugin on the client thread. Every other method that clicks or waits must run on a script thread.
