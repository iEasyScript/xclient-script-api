ClientScripts

public final class ClientScripts

Runs the game's own client scripts (CS2) by id.

Client scripts are the small programs in the game cache that drive interfaces: switching tabs, scrolling a list, opening a pop-up, reading a quest's state. Look a script up in RuneLite's decompiled cs2-scripts repository (or net.runelite.api.ScriptID) to find its id and the arguments it takes, then call it here. The decompiled files are for reading; what runs is the script of that id in the game's own cache. 


ClientScripts.run(915, 3);                                      // tab switch script, inventory tab
int state = ClientScripts.runForInt(ScriptID.QUEST_STATUS_GET, questId).orElse(-1);

Arguments must be Integer or String, in the order the script declares them; a wrong count or type usually makes the game drop the call or misbehave rather than fail loudly.

Every method is safe to call from a script thread: it runs the script on the client thread and, except runLater, waits for it to finish. The game cannot run a client script from inside another one, so from an event handler that fires during a script (a ScriptPreFired, ScriptPostFired or ScriptCallbackEvent subscriber) use runLater.
