Objects

public class Objects

Scene objects: finding them (game, ground, wall and decorative objects), reading their definitions, and clicking their menu options.

query is the modern entry point over the tile-object cache. The long tail of getXxxObject(s) and find* overloads is the older API that old scripts still call; all of them end in one scene sweep whose tile walk runs as a single client-thread hop, after which the caller's predicate and the nearest-first sort run on the calling thread.

Units: overloads anchored on a WorldPoint take their distance in tiles, overloads anchored on a LocalPoint take it in local units (128 per tile). Without a distance the radius is half the scene (52 tiles), and nothing reaches past the scene (104 tiles).

The class also mirrors java.util.Objects: it shares that simple name, so scripts that lost the java.util import keep compiling and behave the same.
