AntibanSettings

public class AntibanSettings

The antiban switches.

Scripts assign the public fields directly (old script jars do so with putstatic), so the live values are often a script's rather than the user's. Next to them this class keeps the user's settings: the values the user chose on the panel, saved in the profile. Scripts can be overruled by the user's override switch, and get the user's values back when they stop.

The fields are plain statics written by any thread without locking. Every method that touches the user layer locks on this class.
