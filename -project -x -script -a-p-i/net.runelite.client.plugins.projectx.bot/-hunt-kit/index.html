HuntKit

public final class HuntKit

The Huntsman's kit: opening, closing, filling and emptying its window, reading what it holds, withdrawing from its grid and depositing from the side inventory while the window is open.

The contents come from a cache rebuilt on the client thread whenever the kit container changes (the plugin forwards those events to updateLocalKit). Queries read the cache and are safe on any thread, as are isOpen and requestOpenView. Everything that waits must run on a script thread. Withdraw and deposit actions do not wait for the inventory to change, and the cache only refreshes on the next container event.
