Antiban

public class Antiban

The antiban as scripts see it: pick an activity, then call actionCooldown and takeMicroBreakByChance between actions.

Both of those are also called from the client thread (through the antiban plugin's xp handler), so they never throw for normal input and never wait on anything except the short random pause before a random mouse move, which is a no-op on the client thread.
