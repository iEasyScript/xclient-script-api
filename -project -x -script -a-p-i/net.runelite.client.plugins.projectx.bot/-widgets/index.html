Widgets

public class Widgets

Finding, reading and clicking interface components.

Lookups hop to the client thread (inline when already on it) and are safe from any thread. Clicks are plain mouse clicks on a component's bounds, so the game runs its own left-click option there; only clickWidgetFast dispatches a menu entry. Waits are for script threads and return false straight away on the client thread.
