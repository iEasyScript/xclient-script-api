Worlds

public class Worlds

Which worlds the account may use, picking one (by population, ping, region or at random), hopping with retries, choosing a login world, and remembering that a profile is a member.

World data comes from RuneLite's cached web world list, so World, WorldType and WorldRegion here are the web types, not the game API's. The list is missing until it has loaded; every method then returns its failure value. Hopping and login methods wait, so call them from a script thread, never the client thread.
