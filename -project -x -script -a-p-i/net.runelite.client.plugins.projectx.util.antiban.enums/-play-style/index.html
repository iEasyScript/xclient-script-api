PlayStyle

public enum PlayStyle

How long an action cooldown lasts, in game ticks, and how long the player "stays focused" before drifting to a neighbouring style.

Every constant is one shared, mutable object: scripts and the antiban plugin all read and change the same current intervals, wave parameters and attention clock.
