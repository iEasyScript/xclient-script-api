Activity

public enum Activity

What a script says it is doing. Each entry names the activity as the panel shows it, the busy rule (Category) the cooldown waits on, and how hard the activity is played (ActivityIntensity).

The list is hand-kept game data. Old script jars refer to the constants by name and the profile panel lists the texts, so names, order and values stay as they are.
