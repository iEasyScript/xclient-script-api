ScriptPanel

public final class ScriptPanel

A script's on-screen panel, in the Project X house style: a title bar with the version and the run time, a status line, then sections of label/value rows and progress bars.

Built afresh every frame -- it is a list of lines, cheap to make -- and drawn in one go: 


ScriptPanel.create("Agility", version)
        .startedAt(script.getStartedAt())
        .status(script.getStatus())
        .section("EXPERIENCE").skill(skills, Skill.AGILITY)
        .section("SESSION").row("Laps", laps + " (" + ScriptPanel.perHour(laps, skills.elapsedMs()) + "/h)")
        .render(graphics);

Usually used through ScriptPanelOverlay, which owns the overlay boilerplate and keeps a mistake in one script's panel from taking the whole overlay down.
