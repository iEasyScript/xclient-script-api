SkillTracker

public final class SkillTracker

Experience gained since a script run started, per skill: XP, XP an hour, levels gained and time to the next level.

Keep one per overlay and call observe at the top of every render, on the client thread. A new start time -- the script was stopped and started again -- resets every skill, so the numbers always describe the current run.
