ScriptPanelOverlay

public abstract class ScriptPanelOverlay extends Overlay

An overlay that draws a ScriptPanel. A script's overlay extends this and fills the panel in build; position, layering and drawing are handled here.

A mistake in build -- a null nobody expected, a widget that is not loaded -- does not take the overlay down: a bare panel is drawn instead, with the error as its status line, and the error is logged at most once a minute.
