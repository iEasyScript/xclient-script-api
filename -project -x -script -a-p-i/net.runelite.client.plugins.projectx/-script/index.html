Script

public abstract class Script extends Global implements IScript

Base class for every script.

A script schedules its loop on scheduledExecutorService in its own run(), keeps the handle in mainScheduledFuture, and starts each pass with super.run(), which returns false whenever the pass should be skipped (a blocking event is being handled, scripts are paused, or the thread was interrupted).

The fields below are written directly by existing scripts, so their names, types, modifiers and static-ness are fixed.
