ProjectX

public class ProjectX

The static entry point scripts and helpers use to reach the game, the client's services and the shared caches.

Collaborators are filled in by Guice static injection (requestStaticInjection) once the injector exists. Until then every getter returns null, and the class must still load and show start-up error dialogs, so nothing here touches the client while the class initialises.

Inside this class collaborators are always fetched through their getters, never the fields, so tests that stub the getters (static mocks) or swap the fields (reflection) are both honoured.
