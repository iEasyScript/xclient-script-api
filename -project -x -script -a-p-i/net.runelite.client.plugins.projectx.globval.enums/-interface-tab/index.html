InterfaceTab

public enum InterfaceTab

The side-panel tabs of the game frame.

Each tab knows the varbit that stores the player's hotkey for it and the panel index the game reports in the TOPLEVEL_PANEL client varc when that tab is open. The declaration order is part of the script API and is not the on-screen order.
